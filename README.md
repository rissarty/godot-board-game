# 🎲 Godot Board Game

A turn-based **board-game/roguelite** built with [Godot](https://godotengine.org/), combining traditional board-game mechanics with cards, events, AI players, and RPG-style progression.

> **Status:** 🚧 Active development

## About

This project started as an exploration of how traditional board-game mechanics could be combined with roguelite elements and different gameplay systems.

The goal is to build a flexible foundation that can eventually support both **local and multiplayer gameplay**, while keeping the underlying systems easy to expand and experiment with.

The project is also a learning project for me, covering areas such as:

* Game architecture
* Turn-based game systems
* UI and scene management
* AI behaviour
* Save/load systems
* Multiplayer networking
* Git-based development

## 🎮 Current Features

* 🎲 Board-based turn system
* 👥 Support for multiple players
* 🤖 AI players with configurable difficulty
* 🃏 Card-based gameplay elements
* 🎯 Random events and special spaces
* 💾 Player/profile-related systems
* 🖥️ Desktop gameplay
* 📱 Accessibility considerations for different screen sizes and input methods

## 🛠️ Built With

## ▶️ Running the Project

### Requirements

* [Godot 4](https://godotengine.org/download/)
* Git

### Setup

Clone the repository:

```bash
git clone https://github.com/rissarty/godot-board-game.git
```

Open the project in **Godot 4** and run the main scene/project.

> Development builds may contain unfinished or experimental features.

## 📚 Why I Built This

This project is primarily a **learning-through-building** project.

Rather than treating the game as only a finished product, I'm using it to understand how larger game projects are structured and how individual systems interact as a project grows.

The multiplayer work in particular is helping me learn about networking, synchronization, client/server architecture, and the problems that appear when moving from a local prototype to an online game.
